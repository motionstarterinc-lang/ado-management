ADO Management

A management platform to help students track, submit, and stay on top of their Accessibility and Disability Services (ADS/ADO) accommodations, semester requests, professor notifications, and renewal deadlines, all in one place.

Why:
Navigating accommodation paperwork every semester (submitting semester requests, forwarding letters of accommodation to each professor, tracking renewal windows) is manual and easy to lose track of. This project aims to streamline that process.

Planned Features:
Track approved accommodations across all enrolled courses in one dashboard. Auto-generate and send accommodation letters/notifications to professors each semester. Reminders for renewal deadlines and semester request windows. Simple status tracking (submitted, pending, confirmed) per course.
